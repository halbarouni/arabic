# مجلّد الخطوط — fonts/

ضع هنا ملفات الخطوط العربية التي تريد أن يقرأها البرنامج: `.ttf` أو `.otf` أو `.woff` أو `.woff2`.

## كيف يقرأها البرنامج

المتصفح لا يستطيع سرد محتويات مجلّد، لذلك يقرأ البرنامج ملف `fonts.json` ليعرف ما بداخل المجلّد. بعد إضافة أي خط، حدّث الملف:

```bash
node make-fonts-manifest.js
```

أو حرّره يدوياً:

```json
{
  "fonts": [
    "Amiri-Regular.ttf",
    { "file": "Aref-Ruqaa.ttf", "name": "عارف رقعة" }
  ]
}
```

الصيغة المختصرة (اسم الملف فقط) تجعل اسم الخط هو اسم الملف بلا الامتداد. استخدم الصيغة الكاملة إذا أردت اسماً عربياً في القائمة.

## شرط مهم

التحميل التلقائي من هذا المجلّد يحتاج تشغيل الصفحة عبر **خادم** (http/https) لا بفتح الملف مباشرة، لأن المتصفح يمنع `fetch` من `file://`. الطرق العملية:

- **GitHub Pages** — يعمل مباشرة بعد النشر.
- محلياً: `python -m http.server` ثم افتح `http://localhost:8000/naqsh-arabic.html`.

وإذا فتحت الملف مباشرة بالنقر المزدوج، استخدم **«أو اقرأ مجلّد خطوط كاملاً»** داخل البرنامج واختر أي مجلّد من جهازك — يعمل في كل الحالات ولا يحتاج خادماً.

## ملاحظة على شكل الحروف

محرّك «تحكّم بكل حرف» يحتاج خطوطاً تحتوي كتلة Arabic Presentation Forms-B. الخطوط التي لا تحتويها (النستعليق غالباً) يكتشفها البرنامج تلقائياً ويحوّلها إلى المحرّك التوافقي وينبّهك.

## الحقوق

لا تضع في هذا المجلّد خطوطاً لا تملك حقّ توزيعها. إن كنت ستنشر المستودع للعموم، اقتصر على الخطوط ذات الرخص الحرّة مثل رخصة الخطوط المفتوحة (OFL).
